# 백석기계공업고등학교 탐험

마우스로 학교 교정을 좌우로 이동하며 캐릭터별 분실물을 찾는 픽셀 게임입니다.

주요 기능

- 기태하·강무결 캐릭터 선택
- 교정 중앙에서 시작하여 왼쪽과 오른쪽 탐색
- 찾아야 하는 물건 3개: 왼쪽 1개, 오른쪽 2개 배치
- 강윤혜·주인하·배하린·공주야 NPC 4명 전원 등장
- NPC의 출현 순서 무작위 적용 및 NPC 사이 간격 확대
- 함정 아이템 클릭 시 체력 32 감소
- 특수 아이템 10종 클릭 시 체력 30 감소 및 개별 메시지 출력
- 아이템·대화 메시지 출력 중 제한 시간 정지
- 꽃잎 연출, 제한 시간, 성공·실패, 비밀번호 0427 편지 기능
- PC·모바일 반응형 화면

GitHub Pages에는 ZIP의 파일들을 저장소 루트에 업로드하면 됩니다.

## 글꼴

게임의 모든 텍스트에는 RoundedFixedsys(DungGeunMo) 웹폰트가 적용되어 있습니다. PC와 모바일 모두 동일한 CDN 글꼴을 불러옵니다. 인터넷 연결이 없으면 시스템 대체 글꼴이 표시될 수 있습니다.


## 오디오
- START 버튼을 누르면 `assets/audio/bgm.mp3`가 배경음으로 반복 재생됩니다.
- 아이템을 클릭해 습득할 때마다 `assets/audio/pickup.mp3` 효과음이 재생됩니다.
- 위험 기억 경고창의 기존 효과음은 `assets/audio/warning.mp3`입니다.
